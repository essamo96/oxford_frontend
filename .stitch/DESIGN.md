# دليل الهوية البصرية وعناصر واجهة المستخدم (DESIGN.md)

مرحباً بك في دليل التصميم والهوية البصرية الخاص بموقع **Full Mark Academy** (أكاديمية الفول مارك). تم إعداد هذا الملف لتوثيق الألوان، الخطوط، المساحات، وعناصر واجهة المستخدم (UI Elements) المبرمجة بالكامل في ملفات الـ CSS لتسهيل الاستخدام والتطوير المتناسق.

---

## 1. الهوية البصرية (Visual Identity)

### 1.1 الخطوط المستخدمة (Typography)
تعتمد الواجهة على نظام خطوط ديناميكي يتغير تلقائياً حسب لغة المتصفح واتجاه الصفحة (RTL/LTR):

*   **اللغة العربية (Arabic Font):** 
    *   الخط الأساسي: `'Tajawal'` و `'Almarai'`
    *   الأوزان المتوفرة: Light (300)، Regular (400)، Bold (700)، Extra Bold (800).
    *   متوفر عبر متغير CSS: `--font-ar`
*   **اللغة الإنجليزية (English Font):** 
    *   الخط الأساسي: `'Outfit'` و `'Inter'`
    *   الأوزان المتوفرة: من Light (300) حتى Black (900).
    *   متوفر عبر متغير CSS: `--font-en`
*   **خط العناوين والعرض (Display Font):**
    *   متغير CSS: `--font-display`

```css
/* مثال للتطبيق التلقائي */
body {
  font-family: var(--font-en);
}
[dir="rtl"] body {
  font-family: var(--font-ar);
}
```

### 1.2 الألوان والسمات (Colors & Themes)
يدعم الموقع ثلاثة سمات لونية فاخرة يتم التحكم بها من خلال الفئات (`.theme-gold`, `.theme-light`, `.theme-dark`) المضافة لعنصر الجسم أو الحاوية:

#### أ. السمة الذهبية الكلاسيكية الفاخرة (`.theme-gold`) - افتراضي

| :--- | :--- | :--- |

| `--bg-secondary` | الخلفية الثانوية | `#0d0a06` (بني داكن جداً) |
| `--bg-tertiary` | الخلفية الثالثة | `#17130b` |
| `--text-primary` | النص الأساسي | `#fbfbf9` (أبيض دافئ) |
| `--text-secondary`| النص الثانوي | `#d1c7bd` (بيج فاتح) |

#### ب. السمة الداكنة التقنية (`.theme-dark`)
تتميز باللون الكحلي الداكن الممزوج بالتوهج السيبراني النيون:

### 1.3 المساحات والأبعاد (Spacing & Dimensions)

*   **عرض الحاوية الأقصى (Container Width):** `1280px` (`--container-width`)
*   **ارتفاع القائمة العلوية (Navbar Height):** `80px` في الوضع الافتراضي و `70px` عند التمرير لأسفل (`--navbar-height` / `--navbar-height-scroll`).
*   **هرمية الطبقات (Z-Index Hierarchy):**
    *   الخلفية المتفاعلة (`--z-bg`): `-1`
    *   العنصر الافتراضي (`--z-base`): `1`
    *   الهيدر المثبت (`--z-header`): `100`
    *   القوائم المنسدلة (`--z-dropdown`): `200`
    *   النوافذ المنبثقة (`--z-modal`): `500`

## 2. عناصر واجهة المستخدم والأنماط (UI Elements & Styles)

### 2.1 حواف العناصر (Border Radius)
نستخدم نظام حواف دائري متناسق لجميع العناصر والبطاقات:

```css
--radius-xs: 4px;     /* للعناصر الصغيرة جداً مثل خطوط الديكور */
--radius-sm: 8px;     /* للأزرار الصغيرة والشارات */
--radius-md: 12px;    /* للمدخلات، القوائم الصغيرة والأكورديون */
--radius-lg: 16px;    /* للبطاقات الكبيرة والأقسام */
--radius-xl: 24px;    /* للحاويات الضخمة والصور البارزة */
--radius-full: 9999px;/* للحصول على شكل دائري كامل */
```

### 2.2 الأزرار (Buttons)
يحتوي النظام على نوعين رئيسيين من الأزرار المصممة بشكل متطور وراقي:

#### أ. زر الفخامة التفاعلي (`.btn-luxury`)
زر ذو تعبئة متدرجة بلون الهوية، يحتوي على تأثير لمعان داخلي يتحرك عند تمرير الفأرة (Hover Effect) وارتفاع ثلاثي الأبعاد بسيط.

```html
<button class="btn btn-luxury">اشترك الآن</button>
```
*   **تأثير التمرير (Hover):** يرتفع للأعلى بمقدار `2px` مع توهج سفلي ناعم (`--accent-glow`).

#### ب. زر الزجاج الشفاف (`.btn-glass`)
زر شفاف يعتمد على تصفية الخلفية وتأثير الزجاج (Glassmorphism) مع حدود ناعمة.

```html
<button class="btn btn-glass">معرفة المزيد</button>
```
*   **تأثير التمرير (Hover):** تتغير الحدود للون الهوية المميز مع زيادة وضوح الخلفية الزجاجية.

---

### 2.3 المكونات الزجاجية والبطاقات (Glassmorphism & Cards)

#### أ. اللوحات الزجاجية (`.glass-panel`)
تصميم زجاجي عصري يعتمد على تضبيب الخلفية وتحسين التباين، مجهز بفلتر ذكي:
*   `backdrop-filter: blur(16px);`
*   يحتوي على لمعان داخلي ذكي بواسطة العنصر الزائف `::before` ليعطي إيحاءً بالعمق ثلاثي الأبعاد.

```html
<div class="glass-panel">
  <h3>محتوى اللوحة الزجاجية</h3>
</div>
```

#### ب. البطاقات المضيئة (`.glow-card`)
بطاقة تحتوي على حدود مضيئة هادئة تظهر فقط عند تحويم الفأرة فوقها:
*   التحكم متوفر عبر الكلاس: `.glow-card`

#### ج. الكروت السداسية التفاعلية (`.hexagon-card` & `.hexagon-wrapper`)
تستخدم لعرض الميزات والخدمات. عند الوقوف على الكرت يدور الرمز الداخلي بشكل لافت بزاوية 360 درجة ويتمدد قليلاً لجذب انتباه المستخدم.

---

### 2.4 حقول المدخلات المبتكرة (Floating Inputs)
مجموعات إدخال مصممة بأسلوب رائع بحيث يرتفع الملصق النصي (Label) للأعلى ويتقلص حجمه عندما يكون الحقل نشطاً أو يحتوي على نص.

```html
<div class="floating-input-group">
  <input type="text" id="username" placeholder=" " required>
  <label for="username">الاسم الكامل</label>
</div>
```
*   *ملاحظة:* تم برمجة دعم كامل للـ RTL بحيث يتم محاذاة النص والملصقات تلقائياً لليمين عند تفعيل اتجاه اللغة العربية.

---

### 2.5 الحركات والمؤثرات (Animations & Transitions)

تحتوي الهوية البصرية على مجموعة من الحركات المبرمجة بالكامل في مجلد الـ `css/animations`:

1.  **حركات الطفو المستمر (Floating):** لعمل تأثير حركة لطيفة للأشكال التجميلية في الخلفية.
    *   `.float-slow` (حركة بطيئة وهادئة)
    *   `.float-medium` (حركة متوسطة)
    *   `.float-fast` (حركة خفيفة سريعة)
2.  **التمرير الظاهر التفاعلي (Scroll Reveal):**
    *   `.reveal`: يرتفع تدريجياً للأعلى عند التمرير.
    *   `.reveal-left` / `.reveal-right`: يتحرك من الجوانب للداخل.
    *   `.reveal-scale`: يتضخم تدريجياً ليكتمل حجمه.
    *   *كلاس التفعيل التلقائي بالـ JS:* `.reveal-active`
    *   *التأخير المتدرج (Stagger Delays):* `.delay-1` إلى `.delay-5`.
3.  **العرض ثلاثي الأبعاد والتحويم (`.dashboard-frame-3d` / `.tilt-wrapper`):**
    *   يعمل على إمالة الصور أو الحاويات بزاوية ثلاثية أبعاد مميزة، وتستوي تماماً عند التحويم عليها لجعل الموقع ينبض بالحياة.

---

> [!TIP]
> **نصيحة للمطور:** 
> للحفاظ على تناسق الهوية البصرية، تجنب استخدام ألوان أو حواف عشوائية صلبة (Inline Styles). استخدم دائماً متغيرات الـ CSS المحددة في هذا الملف لكي يستجيب موقعك لتغيير السمات (Themes) وتغيير وضع القراءة ليلاً/نهاراً بسلاسة تامة.
